# 1.0.7 安装与发版测试清单

> 适用版本：`1.0.7`  
> 适用环境：本地 Docker / 宝塔 MySQL + Node API

## 1. 发布前准备
1. 确认代码版本为本次提交版本（`git log -1`）。
2. 确认数据库已备份（至少保留 1 份 SQL 全量备份）。
3. 确认后端数据库连接配置正确（`config.prod.js` 或环境变量 `UIED_DB_*`）。
4. 确认 API 进程已重启并可访问：`/api/site-info` 返回 `code:0`。

## 2. 已安装环境（菜单补丁）
1. 执行菜单补丁 SQL：
   - 文件：`server/sql/patch_2026_0318_commercial_delivery_top_menu.sql`
2. 执行后核对菜单：
   - `1101` 商业授权（一级）
   - `1102` 交付中心（一级）
   - `864` 许可证中心（挂到 1101）
   - `894` 交付初始化（挂到 1102）
   - `866` 功能开关（`is_show=0`）
3. 退出并重新登录后台，确认左侧菜单立即生效。

## 3. /install 安装向导测试
1. 访问 `/install`，页面可打开且不走前台主布局。
2. “环境检测”应返回以下关键项：
   - Node.js
   - MySQL
   - Redis（允许 warn，不阻断）
   - 核心数据表
   - 目录写入权限
3. 当存在 `fail` 项时，初始化按钮不可执行（或执行后明确报错）。
4. 填写管理员与站点信息，执行初始化成功后提示可去 `/admin` 登录。
5. 初始化成功后再次执行，应提示“系统已安装”并阻止重复初始化。

## 4. 商业菜单与授权页验证
1. 打开后台 `商业授权 -> 许可证中心`：
   - 页面能加载“授权运行状态”与“商业版健康总览”。
2. 打开后台 `交付中心 -> 交付初始化`：
   - 能看到模板、模块开关、预览与执行结果区域。
3. 在投稿激励/商业位等受限页面，未授权提示文案应为“请到商业授权菜单升级后再使用”。

## 5. API 验证清单（可直接 curl）
1. `GET /api/install/status`
2. `GET /api/install/env-check`
3. `GET /api/uied/license/info`
4. `GET /api/uied/commercial/overview`
5. `GET /api/site-info`

预期：以上接口返回 `code:0`，且无 502/500。

## 6. 前台验证
1. 首页与热门页可正常打开，无全站 502。
2. `/install` 页面可独立访问（未安装环境优先测试）。
3. 站点信息、SEO 基础信息可正常读取（`/api/site-info`）。

## 7. 回滚预案（最小化）
1. 代码回滚到上一个稳定 commit。
2. 数据库回滚到发布前备份。
3. 重新启动 API 并验证 `GET /api/site-info`。
