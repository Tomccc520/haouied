# 1.0.2 版本开发记录（2026-03-07）

## 一、需求清单
1. 后台菜单中“工作台”调整到第一位（首页位置）。
2. 前端热门推荐区域默认展示三行卡片。
3. 启用并增强 ref 参数能力（保留 UTM 等原有统计参数）。
4. 网址详情页正文文字间距过大，需对齐后台编辑器阅读体验。
5. 修复网址管理草稿筛选：已发布数据不应出现在草稿列表。
6. 后台菜单设计与交互统一重构，并沉淀可复用 skill。
7. 修复更新记录页“当前网站总数显示为 0”的统计逻辑。
8. 后台菜单选中态改为无整块底色，仅保留文字/图标/边线高亮。
9. 修复“前端配置-社交媒体”保存后前台页脚不生效的问题。
10. 优化后台社交媒体配置页交互与视觉，提升可运营性。
11. 社交媒体编辑支持“URL 输入 + 素材中心选择”双通道（图标/二维码）。
12. 所属分组支持自定义昵称和自定义图标（素材中心图标库）。
13. 页脚关于区域（footer-about-section）后台化，支持文案与按钮配置。
14. 社交媒体配置页视觉继续优化，需贴近前台“一行三个图标”的运营预览体验。
15. 社交媒体图标配置新增 SVG 图标库能力（svg:key），并确保前台可渲染。
16. 首页分类区子分类标签右侧增加“查看分类”快捷按钮，并优化与分页控制的一致性。

## 三、影响评估
- 不涉及数据库结构/表字段变更；涉及补丁语法兼容调整（5.6 可执行性提升）。
- 本地配置保持原默认数据库（Docker 3308），可通过环境变量切换到宝塔/本机 MySQL。
- 主要为前端展示、外链拼接、后台菜单交互与列表筛选逻辑优化。
- 后台配置项保持兼容，原有开关可继续使用。
