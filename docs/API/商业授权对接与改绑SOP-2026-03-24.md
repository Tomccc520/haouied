# UIED-NAV 商业授权对接与改绑 SOP（fsuied.com）

## 1. 商业规则（已确认）

- 售卖版本只有 `Pro` 和 `Enterprise`（不再售卖 Free）。
- `Pro` 与 `Enterprise` 都开放完整功能能力（功能不做分层差异）。
- 两个版本都为永久授权（`expiresAt = 0`）。
- `Pro`：固定限制 `3` 个域名。
- `Enterprise`：企业源码交付，不限制域名数量。
- 两个版本都必须走授权签名校验。

## 2. 当前源码侧已落地规则（本次改造）

> 菜单重命名补丁：若你的数据库仍显示“许可证中心”，执行  
> `server/sql/patch_2026_0324_license_center_rename.sql` 可统一改为“授权中心”。

### 2.1 运行时授权判定

- `Pro / Enterprise` 强制签名校验。
- `Pro` 强制域名额度校验（固定 3 域名）。
- `Enterprise` 不做域名数量限制（源码交付口径）。
- `Pro / Enterprise` 生效后均开放完整功能能力（含 enterprise 功能键）。

### 2.2 激活与保存规则

- 客户后台激活入口改为“授权码 Key 激活”（不再手填 JSON）。
- 系统会用授权码向 fsuied.com 拉取完整签名授权，再本地落库。
- `Pro / Enterprise` 保存时必须携带有效 `signature`，否则拒绝保存。
- 更新许可证后，系统会自动清空“运行时自动绑定域名”缓存，避免改绑后旧域名继续占额度。

### 2.3 本地签发开关

- 默认禁止当前实例本地签发许可证。
- 仅当环境变量 `UIED_ENABLE_LOCAL_LICENSE_SIGN=true` 时，才允许调用本地签发接口。
- 客户部署实例必须保持关闭（默认即可）。

### 2.4 安装激活守卫（新增）

- 默认开启 `UIED_REQUIRE_PAID_LICENSE_ACTIVATION=true`。
- 后台登录后访问 `/api/uied/**` 业务接口时，若未导入有效 `Pro/Enterprise` 授权，会被统一拦截（HTTP 402）。
- 授权中心接口（`license/info|activate|save|verify` 等）允许直通，便于首次安装时先激活授权。
- 前台公开接口不受该守卫影响。

## 3. 你在 fsuied.com 需要开发什么

你理解是对的，**改绑与签发应该在 fsuied.com 授权中心做**。建议实现下面 4 个模块：

1. 订单授权模块
- 支付成功后自动创建授权记录（licenseKey、版本、客户信息）。
- 生成并保存“当前授权域名列表”。

2. 签发模块（核心）
- 按订单信息生成许可证 payload。
- 用 fsuied.com 签名密钥签名，返回完整授权 JSON。
- 仅 fsuied.com 保留签名能力，客户侧源码不开放。

3. 改绑审批模块
- 提交改绑申请（原域名、新域名、原因、订单号）。
- 后台审核通过后，更新授权域名并重新签发许可证。
- 保留改绑审计日志（谁审批、何时改绑、改绑前后差异）。

4. 下载交付模块
- 用户中心展示授权码（licenseKey）与源码包下载。
- Pro/Enterprise 都保留签名授权载荷生成能力（供客户实例按 key 拉取）。

## 4. 推荐的数据结构（fsuied.com）

建议最少包含 3 张表：

- `licenses`
  - `license_key`（唯一）
  - `edition`（pro/enterprise）
  - `status`（active/disabled）
  - `domain_limit`（pro=3, enterprise=9999 占位）
  - `domain_whitelist_json`
  - `issued_at`
  - `expires_at`（固定 0）
  - `customer_name`、`company_name`、`contact_email`
  - `note`

- `license_rebind_orders`
  - `id`
  - `license_key`
  - `from_domain`
  - `to_domain`
  - `reason`
  - `status`（pending/approved/rejected）
  - `approved_by`、`approved_at`

- `license_issue_logs`
  - `id`
  - `license_key`
  - `action`（issue/rebind/renew/manual_fix）
  - `payload_snapshot_json`
  - `operator`
  - `created_at`

## 5. 授权载荷格式（fsuied.com 返回给客户实例）

```json
{
  "edition": "pro",
  "status": "active",
  "licenseKey": "UIED-PRO-XXXX-XXXX",
  "customerName": "张三",
  "companyName": "某某公司",
  "contactEmail": "xx@xx.com",
  "domainLimit": 3,
  "domainWhitelist": ["demo.xx.com"],
  "issuedAt": 1767225600,
  "expiresAt": 0,
  "note": "Pro永久授权",
  "signVersion": "v1",
  "signature": "<hmac-sha256-hex>",
  "updatedAt": 1767225600
}
```

> Enterprise 同结构，`edition=enterprise`，`expiresAt=0`，`domainLimit` 可固定为 `9999` 占位。
> 客户后台不再要求手贴该 JSON；默认只输入授权码，由系统自动拉取此载荷。

## 6. 对接流程（端到端）

### 6.1 首次授权（按 Key 激活）

1. 用户在 fsuied.com 下单并支付成功。
2. fsuied.com 根据订单生成 license payload 并签名。
3. 用户获得授权码 `licenseKey`。
4. 用户在客户后台 `授权中心` 输入授权码（可选输入绑定域名）。
5. 客户系统调用 `/api/uied/license/activate` 向 fsuied.com 拉取签名授权并落库。
6. 许可证生效后，后台安装激活守卫放行，系统按 `effectiveEdition` 生效全部功能。

### 6.2 改绑流程

1. 用户在 fsuied.com 提交改绑申请。
2. 审核通过后，fsuied.com 更新域名白名单并重新签发 license。
3. 用户在客户后台再次输入同一授权码激活（系统会拉取最新重签授权）。
4. 客户系统保存后会清空旧的运行时域名绑定缓存。
5. 新域名首次访问自动登记（Pro 在 3 域名额度内）。

## 7. fsuied.com 推荐接口（供你实现）

### 7.1 签发/重签

- `POST /api/license/issue`
- 入参：`orderNo`, `licenseKey`, `edition`, `customer`, `domainWhitelist`, `note`
- 出参：完整授权 JSON（含 `signature`）

### 7.2 申请改绑

- `POST /api/license/rebind/apply`
- 入参：`licenseKey`, `fromDomain`, `toDomain`, `reason`
- 出参：申请单号、状态

### 7.3 审核改绑并重签

- `POST /api/license/rebind/approve`
- 入参：`rebindId`, `approve=true|false`, `comment`
- 出参：若通过返回新授权 JSON（含 signature）

### 7.4 查询授权（供客户实例按 key 激活）

- `GET /api/license/detail?licenseKey=...&bindDomain=...`
- 返回当前授权版本、域名列表、改绑历史，以及可直接落库的签名授权载荷（字段见第 5 节）。

推荐响应示例：

      "edition": "pro",

## 8. 安全要求（必须）

1. `UIED_ENABLE_LOCAL_LICENSE_SIGN`
- 客户部署实例：`false`（默认）
- fsuied.com 授权中心实例：`true`（仅此实例）

2. `UIED_LICENSE_SIGN_SECRET`
- fsuied.com 使用高强度密钥（32+ 随机字符串）。
- 当前源码为 `v1(HMAC)` 验签模型：签发端与验签端需要同一密钥才能验签。
- 若你要求“签发密钥与客户实例彻底隔离”，需升级为非对称签名（私钥仅在 fsuied.com、公钥在客户实例）。

3. 客户侧禁止“自签发”
- 客户环境只允许导入签名后的授权文件。
- Pro/Enterprise 无签名或签名无效直接拒绝。

4. 客户后台授权页面（admin）
- 当前源码仅保留“客户激活页”：输入授权码、激活授权、查看运行状态。
- 不再暴露商业模式开关与健康总览等内部运营项。
- 页面内固定购买链接：`https://fsuied.com/products/10`

## 9. 验收清单

- Pro 按 key 激活后是否固定 `3` 域名额度，且全部功能可用。
- Enterprise 按 key 激活后是否为永久授权、不受域名额度影响，且全部功能可用。
- Pro/Enterprise 不带签名是否保存失败。
- 用错误签名保存是否失败。
- 改绑后再次按 key 激活，旧域名是否不再占用额度。
- 客户实例是否无法调用本地签发接口（返回 403）。
- 未激活授权时，后台业务接口是否返回 402（仅授权中心可操作）。

## 10. 双本地联调（fsuied 本地 + hao 本地）

1. 准备两个本地实例（建议不同端口）  
- `A实例（fsuied 本地授权中心）`：负责签发 / 改绑审批。  
- `B实例（hao 本地客户站）`：负责按 key 激活授权、运行校验。  
- 建议 hosts 绑定两个本地域名（便于测试域名限制），例如：  
  - `127.0.0.1 license-local.fsuied.test`  
  - `127.0.0.1 hao.uied.local`

2. A实例（fsuied 本地）环境变量  
- `UIED_ENABLE_LOCAL_LICENSE_SIGN=true`  
- `UIED_LICENSE_SIGN_SECRET=<你的签名密钥>`  
- `UIED_REQUIRE_PAID_LICENSE_ACTIVATION=false`（授权中心自身可按需关闭拦截）

3. B实例（hao 本地）环境变量  
- `UIED_ENABLE_LOCAL_LICENSE_SIGN=false`  
- `UIED_LICENSE_SIGN_SECRET=<与A实例一致，仅v1模型需要>`  
- `UIED_REQUIRE_PAID_LICENSE_ACTIVATION=true`
- `UIED_LICENSE_ACTIVATE_ENDPOINT=<A实例激活接口，如 http://license-local.fsuied.test:8002/api/license/detail>`
- `UIED_LICENSE_ACTIVATE_METHOD=GET`（或与你的 fsuied 接口一致）

4. Pro 完整链路联调  
- 在 A实例创建 Pro 授权，拿到 `licenseKey`。  
- 在 B实例后台“授权中心”输入授权码激活。  
- 校验：`status=active`、`domainLimit=3`、后台业务接口放行。

5. Enterprise 完整链路联调  
- 在 A实例创建 Enterprise 授权，拿到 `licenseKey`。  
- 在 B实例输入授权码激活并校验：不触发域名额度拦截、后台业务接口放行。

6. Pro 改绑链路联调  
- 在 A实例提交改绑申请 -> 审核通过 -> 重签新授权。  
- 在 B实例再次输入同一授权码激活。  
- 校验旧域名不再占额度、新域名可用。

7. 激活拦截回归（必测）  
- 清空 B实例授权信息后访问后台业务接口，应返回 `402`。  
- B实例仍可访问“授权中心”接口并重新激活授权。  
- 导入成功后再次访问后台业务接口，应恢复正常。

## 11. 客户真实交付流程（宝塔部署）

1. 在 fsuied.com 完成购买  
- 商品固定入口：[https://fsuied.com/products/10](https://fsuied.com/products/10)  
- 支付完成后在 fsuied.com 授权中心拿到 `licenseKey`。

2. 在 fsuied.com 先绑定域名  
- Pro：最多 3 个域名。  
- Enterprise：源码交付，不限制域名数量。  
- 建议先绑定客户最终上线域名（如 `hao.uied.cn`）。

3. 客户在宝塔部署 build 后访问安装向导  
- 访问 `https://客户域名/install`。  
- 安装向导先做环境检测、数据库测试，再执行“一键初始化”。

4. 一键初始化时填写授权信息  
- 必填：`授权码 Key`（licenseKey）。  
- 可选：`绑定域名`（bindDomain，留空默认取当前访问域名）。  
- 点击“执行初始化”后，系统会先调用授权中心激活，再创建管理员与站点配置。

5. 安装完成后的验收  
- 成功提示里可看到授权版本（Pro/Enterprise）。  
- 访问 `https://客户域名/admin` 登录后台。  
- 未激活或激活失效时，后台业务接口会返回 `402` 并引导到“授权中心”。
