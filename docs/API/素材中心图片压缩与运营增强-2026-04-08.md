## 2. 后端改动

### 2.1 配置项

- 设置键：`materialUploadConfig`
- 存储位置：`uied_site_setting`
- 默认值：
  - `enabled: false`
  - `applyOnLocalUpload: true`
  - `applyOnRemoteTransfer: true`
  - `remoteNamePattern: "%random%-%date%"`
  - `minSizeKb: 200`
  - `maxWidth: 2560`
  - `maxHeight: 2560`
  - `jpegQuality: 82`
  - `pngCompressionLevel: 9`

说明：
1. 本地上传（`/api/common/upload/image`）支持按配置自动压缩。
2. 远程转存（`/api/common/upload/image/transfer`）支持按配置自动压缩。
3. 远程转存支持“文件名结构模板”（仅影响落盘文件名，不影响素材展示名）。
4. 关闭压缩时按原有路径存储，不影响现有上传流程。

远程文件名模板支持占位符：
- `%filename%` 原文件名（无扩展名）
- `%date%` 完整日期（如 `20260409`）
- `%year%` / `%month%` / `%day%`
- `%time%` 时间（如 `182547`）
- `%timestamp%` Unix 时间戳
- `%md5%` 文件 MD5
- `%random%` 随机串

### 2.2 新增接口

1. `GET /api/common/album/albumUsageDetail?id={id}`
   - 返回素材引用明细（文章/站内文章/网址）
2. `POST /api/common/album/albumRecompress`
   - 入参：`{ id }` 或 `{ ids: number[] }`
   - 支持单图和批量重压缩

### 2.3 元数据回写

压缩或重压缩后自动回写：
1. `la_album.size`
2. `la_album.ext`
3. `la_album_meta.mime_type`
4. `la_album_meta.width`
5. `la_album_meta.height`

## 3. 后台改动（素材中心）

文件：`server/admin/src/components/material/index.vue`

1. 工具栏新增：`批量压缩`、`压缩设置`
2. 右侧媒体详情新增：
   - 引用状态
   - 引用明细（可刷新）
   - 重压缩当前图片
   - 压缩结果提示
3. 新增“素材图片压缩配置”弹窗并可保存到 `materialUploadConfig`
4. 新增权限与容错收口：
   - `批量压缩` 按钮依赖权限：`common:album:albumRecompress`
   - `刷新引用` 按钮依赖权限：`common:album:albumUsageDetail`
   - `重压缩当前图片` 按钮依赖权限：`common:album:albumRecompress`
   - `压缩设置` 按钮依赖权限：`uied:setting:get`
   - 压缩配置读取失败时自动回退默认值，并提示“已使用默认值”
   - 压缩配置保存失败时给出明确提示，不阻断素材页面其他操作

## 4. 使用方式

1. 进入后台 `素材中心`
2. 点击 `压缩设置`，开启压缩并保存参数
3. 上传新图：自动按配置压缩
4. 已有图片：
   - 单图：右侧点 `重压缩当前图片`
   - 批量：勾选后点 `批量压缩`
5. 在右侧查看引用明细，确认是否被文章/网址使用

## 5. 回归清单

1. 开启压缩并上传一张大图，确认文件大小下降（或分辨率按阈值收敛）。
2. 关闭压缩后再上传，确认走原图流程。
3. 对历史图片执行单图重压缩，确认返回“成功/跳过/失败”统计。
4. 对多图执行批量重压缩，确认批量结果提示正确。
5. 点击“刷新引用”，若素材被文章/网址使用，能看到引用条目。
6. 删除被引用素材时仍应被拦截（沿用既有引用保护逻辑）。
