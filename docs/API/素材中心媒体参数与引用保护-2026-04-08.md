# 素材中心媒体参数与引用保护（2026-04-08）

## 1. 本次目标

1. 素材中心右侧“媒体详情”支持编辑并保存：替代文本、标题、说明文字、描述。
2. 素材删除前增加“被引用检测”，已被文章/网址使用的素材禁止删除并返回明确提示。
3. 兼容未执行 SQL 补丁的旧环境：列表可正常使用，保存元数据时给出补丁提示。

## 2. 后端变更

### 2.1 新增接口

- `POST /api/common/album/albumMetaUpdate`
  - 入参：`id`、`alt`、`title`、`caption`、`description`（可选 `mimeType/width/height`）
  - 返回：标准 `{ code, message, data }`

### 2.2 素材列表增强

- `GET /api/common/album/albumList`
  - 追加返回字段：`alt`、`title`、`caption`、`description`、`mimeType`、`width`、`height`
  - 来源：`la_album_meta`（若表不存在则自动降级，不影响列表使用）

### 2.3 删除保护

- `POST /api/common/album/albumDel`
  - 删除前检测引用来源：
    - `la_article.image / la_article.content`
    - `uied_article.cover_image / uied_article.content`
    - `uied_website.thumbnail / icon_url / screenshots / detail_content`
  - 命中引用时返回错误示例：
    - `素材已被引用，无法删除：文章《xxx》、网址《yyy》...`

## 3. 数据库补丁

2. 老客户升级时仍建议按补丁文件执行一次。

## 4. 前端变更

1. 素材中心右侧“媒体详情”改为可编辑表单。
2. 新增“保存媒体信息”按钮，保存后本地列表即时回填，不需要手动刷新。
3. 文件 URL 复制能力保留。

## 5. 回归清单（建议）

1. 进入后台素材中心，选择任意图片。
2. 修改“替代文本/标题/说明/描述”并保存，刷新页面后字段保持不变。
3. 使用同一素材作为文章封面或网址缩略图后，尝试删除该素材，应收到“已被引用”提示。
4. 换一张未引用素材删除，应删除成功。
