# MCP开源清单与使用教程（1.0.9）

## 1. 可直接上架的开源MCP来源

### 1.1 已内置数据包（推荐先用）
- `server/sql/seed_2026_0320_mcp_open_source.sql`
  - 官方核心 + 开发工具 + 数据集成 + 浏览器自动化 + 协作办公。
- `server/sql/seed_2026_0320_mcp_cn_scene_pack.sql`
  - 中文场景扩展（办公/电商/运营），适合国内客户演示与售卖页展示。

### 1.2 当前种子内的典型开源来源
- `modelcontextprotocol/servers` 官方服务集合（如 `filesystem`、`fetch`、`git`、`memory`、`sqlite`、`postgres`、`slack`、`brave-search` 等）。
- 数据包内每条记录都带 `official_url/docs_url/github_url`，便于前台详情页展示“来源链接”。

## 2. 是否可以直接商用展示

可以展示，但建议遵循以下规则：
- 只展示“条目索引与介绍”，不要直接复制第三方长文档原文。
- 每个条目保留来源链接（官网/文档/GitHub）。
- 在你站点的页脚或MCP详情页增加一句“项目来源归属原作者，本站仅做聚合索引”。
- 若某项目 License 有额外要求（商标、署名、二次分发限制），按其仓库 License 执行。

## 3. 导入与发布流程（后台）

### 3.1 导入SQL
1. 执行开源基础包：
   - `server/sql/seed_2026_0320_mcp_open_source.sql`
2. 执行中文场景包：
   - `server/sql/seed_2026_0320_mcp_cn_scene_pack.sql`

### 3.2 后台检查
1. 打开 `后台 -> MCP中心 -> MCP分类`，确认分类已生成。
2. 打开 `后台 -> MCP中心 -> MCP标签`，确认标签已生成。
3. 打开 `后台 -> MCP中心 -> MCP列表`，确认条目状态为“已发布”。

### 3.3 前台验证
1. 列表页：`/mcp`
2. 详情页：`/mcp/:slug`
3. 确认项：
   - SEO 标题/描述可见。
   - 使用教程模块可见。
   - 来源链接可点开。

## 4. 给客户的“使用教程”模板（可直接放详情页或帮助中心）

### 4.1 快速接入四步
1. 在后台发布MCP条目，补齐摘要、分类、标签、SEO。
2. 在详情页核对协议（HTTP/STDIO/SSE）与运行时（Node/Python/Go）。
3. 按文档链接完成鉴权、环境变量和示例请求。
4. 上线后复查可用性与点击数据，持续优化摘要和教程内容。

### 4.2 运营同学常用检查清单
- 条目是否有封面与图标。
- 详情是否包含“适用场景”。
- 是否存在失效外链（官网/文档/GitHub）。
- SEO关键词是否包含分类词 + 场景词。

## 5. 当前版本已支持的MCP页配置（后台）

路径：`网站设置 -> MCP配置`
- 页面启用/关闭
- Hero样式、视觉风格、背景模式
- 卡片风格、圆角、边框色、阴影
- **每页MCP卡片数（listPageSize）**
- 内容最大宽度（maxWidth）
- 分类/标签筛选开关
