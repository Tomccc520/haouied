# UIED-NAV 商业版本信息（1.0.9）

## 1. 产品定位（可直接放上架页）

- 产品名称：`UIED-NAV 商业版源码（React + Node + MySQL）`
- 产品形态：`导航站 + 内容站 + 后台运营系统` 一体化
- 技术栈：
  - 前端官网：React
  - 后台管理：Vue 3 + Element Plus
  - 后端 API：Egg.js + Sequelize + MySQL
- 典型场景：AI工具导航、设计资源导航、行业工具目录、内容化导航站

## 3. 授权机制（上架页推荐文案）

- 版本授权：`Free / Pro / Enterprise`
- 授权方式：`License 文件签名校验 + 功能开关键`
- 域名策略：支持 `域名白名单 + 自动绑定 + 数量上限`
- 失效降级：许可证无效/过期/超限时，自动降级为 Free 能力
- 后台可视：提供许可证中心页面查看生效版本、域名占用、到期状态

## 4. 域名上限售卖建议（建议口径）

> 当前系统支持自定义 `domainLimit`，以下是建议售卖档位：

- Free：`1` 个授权域名
- Pro：`3` 个授权域名
- Enterprise：`不限`（建议配置为较大值，如 `999`）

## 5. 上架卖点（可直接复制）

1. 一套代码支持 Free/Pro/Enterprise 多版本售卖，不需要维护多套分支。
2. 后台可配置能力完整，适合做“可交付、可运营、可持续升级”的源码产品。
3. 内置 SEO 与内容体系，不只是导航目录，能做长期内容运营。
4. 支持安装向导与交付初始化，降低客户部署门槛。
5. 支持域名授权与许可证中心，便于商业化管理和售后升级。

## 6. 交付清单建议（上架说明）

- `frontend` 官网构建产物
- `admin` 后台构建产物
- `server` 后端源码与运行配置
- `sql` 初始化/升级脚本
- `license` 客户授权文件模板
- `部署文档 + 常见问题 + 更新日志`

## 7. 风险提示（内部）

- 若要严格执行“域名数量限制”，需在许可证中心开启 `域名绑定数量限制`。
- 若要防止 license 被篡改，需开启 `强制许可证签名校验`。
- 交付给客户前，建议执行商业版预检脚本，确保功能矩阵和菜单权限一致。
