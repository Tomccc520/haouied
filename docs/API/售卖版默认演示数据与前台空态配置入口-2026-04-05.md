# 售卖版默认演示数据与前台空态配置入口

## 目标

面向正式售卖版，首装后不再是空站：

1. 安装向导默认导入一套可直接展示的演示数据  
2. 前台关键模块无数据时，仅对管理员显示“去后台配置”快捷入口  
3. 普通访客只看到正常空态文案，不暴露后台路径  

## 首装默认数据

安装路径：`/install`

初始化安装新增选项：

- `自动导入默认演示数据（推荐）`

默认开启。执行初始化时会复用 `deliveryInit` 的 `commercial_default` 模板，自动导入：

1. 基础前台配置
2. 示例网址分类
3. 示例网址标签
4. 示例网址
5. 示例文章分类
6. 示例文章标签
7. 示例文章

说明：

1. 不会重复激活授权
2. 不会导入测试用户
3. 最终站点名称/标题/描述/关键词，以安装页填写内容为准

## 前台管理员快捷入口

已接入模块：

1. 首页顶部空态
2. 首页推荐区异常/空态
3. 首页 Banner 空态
4. 首页设计文章模块空态
5. 每日热榜页空态

显示规则：

1. 本地开发环境默认显示
2. 生产环境要求当前同域存在后台登录态（`like_admin_token`）
3. 可通过地址参数 `?adminShortcut=1` 强制预览

普通访客不会看到后台入口按钮。

## 后台跳转路径

当前快捷入口映射：

1. 首页模块配置：`/uied/page`
2. 推荐内容配置：`/system-setting/base-config/content-hub?tab=rankings`
3. Banner 配置：`/uied/operation/commercial-monetization/banner`
4. 每日热榜配置：`/system-setting/base-config/content-hub?tab=dailyHot`

生产环境会自动拼成：

- `/admin + 后台路径`

本地开发环境默认拼成：

- `http://localhost:5173 + 后台路径`

## 本地联调建议

### 安装默认数据

1. 打开 `/install`
2. 填授权码并校验通过
3. 保持“自动导入默认演示数据（推荐）”勾选
4. 执行初始化
5. 安装完成后检查首页、文章列表、热榜页是否已有默认内容

### 前台空态快捷入口

由于本地前后台通常分端口运行，推荐直接带参数预览：

- `http://localhost:3003/?adminShortcut=1`

然后手动制造某个模块空态，确认会出现“去后台配置”按钮。

## 交付建议

对客户的标准话术建议统一为：

1. 首次安装默认导入演示数据，方便快速看到效果  
2. 客户可在后台直接替换为自己的内容  
3. 当前台某个模块未配置时，管理员可直接从前台一键进入后台对应配置页
