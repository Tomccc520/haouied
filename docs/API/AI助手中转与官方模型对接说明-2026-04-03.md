# AI 助手中转与官方模型对接说明（2026-04-03）

## 1. 目标

在 `后台 -> 系统设置 -> 基础配置 -> AI 助手管理` 中，支持以下三类接入：

1. 官方直连（Kimi / 豆包等）
2. 自定义中转 API（OpenAI 兼容协议）
3. 其他兼容提供商（OpenAI 兼容）

> 适用版本：UIED 导航源码 `v1.1.1+`（2026-04-03 后）

---

## 2. 后台新增可选提供商

- `Kimi`
- `豆包（火山方舟）`
- `自定义中转 API（OpenAI兼容）`
- `其他`

选择提供商后，系统会自动填充一组默认 API 地址和模型（可手动修改）。

---

## 3. 推荐填写参数

### 3.1 Kimi（Moonshot 官方）

- Provider: `kimi`
- API 地址（推荐）: `https://api.moonshot.cn/v1/chat/completions`
- 模型（示例）: `moonshot-v1-8k`
- 鉴权头: `Authorization: Bearer <KIMI_API_KEY>`

说明：后台“拉取模型”会优先请求远程 `/models`，失败时自动回退预设模型。

### 3.2 豆包（火山方舟 OpenAI 兼容）

- Provider: `doubao`
- API 地址（推荐）: `https://operator.las.cn-beijing.volces.com/api/v1/chat/completions`
- 模型（官方文档示例）: `doubao-seed-1-6-251015`
- 鉴权头: `Authorization: Bearer <DOUBAO_API_KEY>`

说明：豆包模型名请以你方控制台可用模型为准，建议先用“拉取模型”或官方控制台核对。

### 3.3 自定义中转 API（你自己的网关）

- Provider: `relay`
- API 地址（格式建议）: `https://你的中转域名/v1/chat/completions`
- 模型: 与中转网关支持的模型名一致（如 `gpt-4o-mini` / `deepseek-chat`）
- 要求: 中转服务需兼容 OpenAI Chat Completions 协议

---

## 4. 后台联调流程（3 分钟）

1. 新增 AI 配置，选择对应 Provider。
2. 填写 API 地址、API Key、模型。
3. 点击“测试连接”，期望提示“连接成功”。
4. 点击“拉取模型”，期望看到接口模型列表（失败会自动回退预设，不影响可用性）。
5. 设为默认配置并启用。

---

## 5. 常见问题

### 5.1 测试连接失败（401）

- API Key 错误或过期。
- Key 与模型/服务区域不匹配。

### 5.2 拉取模型失败

- 证书链、网络策略、网关限制导致。
- 系统会自动回退内置预设模型，仍可手工填写模型并测试。

### 5.3 使用中转时模型可测通但业务失败

- 中转实现与 OpenAI 协议字段不完全兼容。
- 检查 `messages`、`model`、`Authorization`、返回结构 `choices[].message.content`。
