# fsuied 本地授权对接最小清单（2026-04-01）

## 1. 目标

让你的本地 `fsuied` 负责签发授权，`HAO UIED` 本地后台输入授权码后可成功激活。

---

## 2. 总流程（你理解的是对的）

1. 在 `fsuied` 侧改好授权查询接口（`/api/license/detail`）  
2. 在 `fsuied` 侧生成并下发授权码（例如 `LIC-...`）  
3. 回到 `HAO UIED` 后台“授权中心”填写授权码激活  
4. 校验激活结果（`isActive=true` / `isSignatureValid=true`）  

---

## 3. fsuied 需要改的最小项

## 3.1 接口放行（关键）

`HAO UIED` 后端会服务端请求：

- `GET /api/license/detail?licenseKey=...&bindDomain=...`

如果你目前返回 `token参数为空`，说明这个接口还在走后台登录鉴权。  
本地联调建议先改成免登录（机器对机器调用最稳）。

建议做法（二选一）：

1. 免登录白名单放行 `license:detail`（推荐）
2. 保留鉴权，但支持固定服务端 Token（需要在 HAO 侧配置 `UIED_LICENSE_ACTIVATE_TOKEN`）

## 3.2 响应格式（必须）

返回结构至少满足：

```json
{
  "code": 200,
  "message": "ok",
  "data": {
    "licensePayload": {
      "edition": "pro",
      "status": "active",
      "licenseKey": "LIC-XXXX",
      "customerName": "张三",
      "companyName": "某公司",
      "contactEmail": "xx@xx.com",
      "domainLimit": 3,
      "domainWhitelist": ["hao.uied.cn"],
      "issuedAt": 1775030000,
      "expiresAt": 0,
      "note": "Pro永久授权",
      "signVersion": "v1",
      "signature": "hmac-sha256-hex",
      "updatedAt": 1775030000
    }
  }
}
```

## 3.3 签发规则（当前项目口径）

- 只卖 `Pro/Enterprise`
- 两者都永久授权（`expiresAt=0`）
- `Pro`：`domainLimit=3`
- `Enterprise`：`domainLimit=9999`（占位，不限域名）

---

## 4. fsuied 本地环境变量（建议）

```bash
UIED_ENABLE_LOCAL_LICENSE_SIGN=true
UIED_LICENSE_SIGN_SECRET=你的签名密钥
```

---

## 5. HAO UIED 本地配置（已在本项目 local 配置中默认指向 8001）

当前本项目本地默认已走：

- `UIED_LICENSE_ACTIVATE_ENDPOINT=http://127.0.0.1:8001/api/license/detail`

你可按需覆盖：

```bash
UIED_LICENSE_ACTIVATE_ENDPOINT=http://127.0.0.1:8001/api/license/detail
UIED_LICENSE_ACTIVATE_METHOD=GET
UIED_LICENSE_ACTIVATE_TOKEN=                # 仅当 fsuied 要求 Token 时填写
UIED_REQUIRE_PAID_LICENSE_ACTIVATION=true
UIED_ENABLE_LOCAL_LICENSE_SIGN=false
UIED_LICENSE_SIGN_SECRET=与fsuied一致（v1模型必须一致）
```

---

## 6. 联调步骤（逐项打勾）

[ ] 1. fsuied 接口可访问：

```bash
curl -sG "http://127.0.0.1:8001/api/license/detail" \
  --data-urlencode "licenseKey=LIC-你的key" \
  --data-urlencode "bindDomain=hao.uied.cn"
```

预期：`code=200` 且 `data.licensePayload.signature` 非空。

[ ] 2. 进入 HAO 后台授权页：

- `/uied/license-center`

[ ] 3. 输入授权码激活

[ ] 4. 激活后校验：

```bash
curl -s http://127.0.0.1:8002/api/uied/license/info
```

预期：

- `isActive=true`
- `isSignatureValid=true`
- `effectiveEdition=pro` 或 `enterprise`
- `licenseKey` 非空

---

## 7. 常见报错与处理

## 7.1 `token参数为空`

原因：`fsuied /api/license/detail` 仍需登录 token。  
处理：放行该接口为免登录，或改为支持服务端固定 Token。

## 7.2 `unable to get local issuer certificate`

原因：调用了 HTTPS 且本地证书链不被信任。  
处理：本地联调改用 `http://127.0.0.1:8001`；生产再用 HTTPS 正式证书。

## 7.3 `status=invalid_signature`

原因：签名校验失败。  
处理：确认 `HAO` 与 `fsuied` 的 `UIED_LICENSE_SIGN_SECRET` 一致（v1 HMAC 模型）。

---

## 8. 结论

你现在就按这个顺序做：

1. 先改 `fsuied` 的 `license/detail` 可调用  
2. 生成 key  
3. 回 `HAO` 后台填 key 激活  

流程是对的。
