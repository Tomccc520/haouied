# UIED-NAV 1.1.3 宝塔命令行部署

本教程适用于宝塔 Linux 面板，通过宝塔终端执行命令。案例域名为 `hao.uied.cn`，客户部署时替换成自己的域名。

## 1. 环境准备

在宝塔安装 Nginx、MySQL、Redis 和 Node.js 18/20，然后在终端检查：

```bash
node -v
npm -v
mysql --version
redis-cli ping
npm install -g pm2
pm2 startup
```

`pm2 startup` 会输出一条带 `sudo/env` 的命令，按输出再执行一次，以保证服务器重启后自动拉起后端。

## 2. 上传并解压

在宝塔新建站点 `hao.uied.cn`，数据库字符集选择 `utf8mb4`。把源码包上传到站点目录后执行：

```bash
cd /www/wwwroot/hao.uied.cn
mkdir -p source
tar -xzf uied-nav-1.1.3-customer-source.tgz -C source
cd source/uied-nav-1.1.3
chmod +x scripts/deploy/baota/*.sh
```

## 3. 生成生产配置

首次运行部署脚本：

```bash
./scripts/deploy/baota/deploy.sh --domain hao.uied.cn
```

脚本会生成 `/www/wwwroot/hao.uied.cn/shared/uied-api.env` 并主动停止。编辑该文件，至少填写：

```env
UIED_DB_USER='宝塔数据库账号'
UIED_DB_PASSWORD='宝塔数据库密码'
UIED_DB_NAME='宝塔数据库名'
UIED_UPLOADS_ABS_DIR=/www/wwwroot/hao.uied.cn/shared/uploads
```

数据库密码含 `#`、空格或特殊符号时必须使用单引号。配置文件权限应保持为 `600`。

## 4. 仅全新客户初始化数据库

以下命令只允许用于全新空数据库：

```bash
./scripts/deploy/baota/init-database.sh \
  --env /www/wwwroot/hao.uied.cn/shared/uied-api.env \
  --confirm-new-database
```

脚本检测到已有核心业务表会立即拒绝执行。`server/sql/install.sql` 包含 `DROP TABLE`，老客户升级严禁运行本步骤。

初始化过程已经包含文章数据源、分类、标签和组件四张基础表；后端启动后也会对缺失的文章源表做兼容自愈，无需客户单独导入 WordPress 历史补丁。

## 5. 一键部署

```bash
./scripts/deploy/baota/deploy.sh --domain hao.uied.cn
```

脚本会完成：

1. 检查 Node.js、npm、rsync、curl 和 PM2。
2. 安装后端生产依赖并生成环境变量化的 Egg 生产配置。
3. 使用 PM2 启动或平滑重载 `uied-api`。
4. 按当前客户域名和数据库重新生成 SEO 前台，并发布管理后台。
5. 检查 `127.0.0.1:8002` 公开接口。
6. 生成 `/www/wwwroot/hao.uied.cn/deploy/uied-nav.nginx.conf`。

服务器内存不足或只想先恢复页面时，可增加 `--prebuilt-frontend` 使用包内预构建前台；正式上线仍建议不带该参数重建一次，避免 SEO 域名和客户内容不一致。

## 6. 配置 Nginx 与 HTTPS

首次上线，把生成的 Nginx 配置作为参考应用到宝塔站点配置。宝塔已有站点配置时不要整段重复粘贴 `server {}`，只合并其中的 `/api/`、`/admin/`、`/` location。

检查并重载：

```bash
nginx -t
/etc/init.d/nginx reload
```

然后在宝塔“网站 -> SSL”中申请证书并开启强制 HTTPS。

## 7. 验收

```bash
pm2 status
pm2 logs uied-api --lines 50
curl -s http://127.0.0.1:8002/api/uied/license/public-status
curl -I https://hao.uied.cn/
curl -I https://hao.uied.cn/admin/
```

后台文章数据源路径：

```text
https://hao.uied.cn/admin/system-setting/base-config/content-hub?tab=wordpress-source
```

点击“一键配置 UIED”，默认接口为 `https://www.uied.cn/api/open/v1/posts`，接口本身包含 `thumbnail` 封面图。

## 8. 后续升级

上传新源码包并解压到新版本目录，确认仍使用原来的 `shared/uied-api.env`，再执行新目录中的部署脚本即可。上传图片位于站点外层 `shared/uploads`，不会因源码目录替换丢失。

老客户升级前必须先备份数据库：

```bash
mysqldump --single-transaction -u数据库账号 -p 数据库名 > /root/uied_backup_$(date +%F_%H%M%S).sql
```

服务重载命令：

```bash
./scripts/deploy/baota/reload-services.sh \
  /www/wwwroot/hao.uied.cn/source/uied-nav-1.1.3 \
  /www/wwwroot/hao.uied.cn/shared/uied-api.env
```

## 9. 从旧 Docker 部署迁移

命令部署与 Docker 不能同时占用 `8002`。如果服务器以前运行过 `uied-api` 容器，先确认数据库与 `shared/uploads` 已备份，再停止旧容器：

```bash
docker ps --format '{{.Names}} {{.Ports}}' | grep 8002
docker stop uied-api
```

部署脚本发现 `8002` 被非 PM2 服务占用时会拒绝继续，不会把旧服务误判为新版本启动成功。

## 10. 安全要求

- 客户站保持 `UIED_ENABLE_LOCAL_LICENSE_SIGN=false`。
- 客户站不要配置 `UIED_LICENSE_SIGN_SECRET` 或授权中心签发密钥。
- 通用源码包不包含 `.license`，正式授权应在部署后单独激活。
- 不要把 `shared/uied-api.env`、数据库备份或正式授权文件转发给其他客户。
