# 菜单交互重构验收清单

## A. 信息架构
- [ ] 工作台位于一级菜单第一项
- [ ] 高频功能在一级菜单可直达（不超过两次点击）
- [ ] 菜单命名统一，不出现同义多名称

## B. 交互行为
- [ ] 搜索框可用，输入后可筛出目标菜单
- [ ] 搜索命中时父级菜单自动展开
- [ ] 搜索无结果时有空态提示
- [ ] 清空搜索后菜单恢复完整树
- [ ] 折叠态/展开态点击路由均正确

## C. 视觉一致性
- [ ] 菜单行高、缩进、图标间距一致
- [ ] hover 与 active 态颜色规则统一
- [ ] light / dark 两种主题下都可识别当前激活项

## D. 质量门槛
- [ ] `server/admin` 执行 `npm run type-check` 通过
- [ ] 涉及后端菜单逻辑时，目标 JS 文件 `node --check` 通过
- [ ] 手工回归至少覆盖：工作台、网址管理、系统设置 三类菜单路径
