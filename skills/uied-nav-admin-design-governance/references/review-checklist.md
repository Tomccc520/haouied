# 后台设计规范评审清单

## A. 一致性
- [ ] 同类页面骨架一致（标题/筛选/列表/分页位置一致）
- [ ] 同类按钮顺序一致（主次关系明确）
- [ ] 同类表单标签宽度一致

## B. 视觉
- [ ] 未出现明显“魔法数”样式（零散 margin/padding/width）
- [ ] 颜色、字号、圆角优先使用全局变量
- [ ] 暗色/浅色主题下都可用（若支持）

## C. 交互
- [ ] 加载、空态、错误态表现一致
- [ ] 危险操作均有二次确认
- [ ] 列表筛选与重置行为一致

## D. 可维护性
- [ ] 新增样式在全局层可复用，不散落页面内
- [ ] 页面代码中内联样式可控（目标持续下降）
- [ ] 复杂区域已拆成组件而非单文件堆叠

## E. 回归建议
- [ ] 抽查 3 个设置页 + 3 个列表页 + 2 个编辑页
- [ ] 检查移动端最小宽度下主要操作可点击
- [ ] 检查分页、弹窗、抽屉在常见数据量下无错位
