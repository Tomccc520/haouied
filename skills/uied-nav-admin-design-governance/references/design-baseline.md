# 后台设计基线（server/admin）

## 1. 页面骨架统一
- 顶部：页面标题 + 简短说明（可选）+ 右侧主操作按钮。
- 中部：筛选区（同一行内字段顺序一致，复杂筛选可折叠）。
- 主体：数据表格或配置表单。
- 底部：分页或保存区域（位置固定，不跳动）。

## 2. 间距与尺寸（建议）
- 区块间距：`24px`
- 组件垂直间距：`16px`
- 行内控件间距：`8px/12px`
- 表单标签宽度：同类页面固定值（如 120 或 140），不要混用。

## 3. 视觉令牌规则
- 颜色、字号、边框、圆角优先使用 `var.css` 中变量。
- 禁止在页面里直接写大量十六进制颜色。
- 新 token 一律加到全局样式层，不放单页私有样式。

## 4. 组件行为统一
- `el-table`：
  - 列标题字号和权重统一。
  - 操作列按钮顺序统一（查看/编辑/删除或业务约定顺序）。
- `el-form`：
  - 标签对齐一致。
  - 错误提示位置一致。
- `el-button`：
  - 主按钮唯一（避免同层多个 primary）。
  - 危险操作统一二次确认文案。

## 5. 代码落地规则
- 优先复用全局样式与通用组件，不复制粘贴页面局部样式。
- 内联样式仅允许临时调试，合并前必须清理。
- 复杂页面拆分子组件，保持主页面可读性。
